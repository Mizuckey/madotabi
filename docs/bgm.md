# BGMリンク

トップ右上の「BGM」から、YouTube・radikoなどのHTTPS URLと任意の名前を登録できます。名前を省略するとドメイン名を使用します。登録後も同じフォームに残ります。

一覧のリンクは別タブで開き、最後にクリックした1件だけを「再生中」と表示します。窓旅から外部サイトの再生状態を検知・操作するものではありません。別のBGMを開いても前のタブの音声は停止しないため、必要に応じて外部タブで止めてください。「表示を解除」は窓旅側の表示のみ解除します。

リンクはSupabaseの `bgm_links` に本人用の情報として保存し、名前の編集、非表示、復元に対応します。URL変更時は新しいURLを登録してください。HTTPS以外、認証情報を含むURL、2048文字を超えるURLは受け付けません。登録先をサーバーで取得せず、SDKや埋め込みプレーヤーは追加していません。

選択状態はユーザー別のsessionStorageに保持し、同じタブの再読み込み後も復元します。他端末の音声状態を推測しないようDBには保存しません。メニューはネイティブdialogで、Escapeで閉じられ、開閉で動画プレーヤーを再生成しません。

## 検証

- Node標準テスト：URL正規化、不正URL拒否、ユーザー別の選択保存・解除、ストレージ拒否時の動作。
- ローカルの検証用Supabase代替で、連続登録、外部タブ遷移と選択切替、名前編集、非表示・復元をブラウザ確認。
- 320px幅でヘッダーの操作領域が重ならず、メニュー内に横スクロールがないことを確認。1100px幅では動画操作とBGMの配置を確認。
- 本番DBのRLS・本人限定の3ポリシー、匿名SELECT不可、物理DELETE権限なしを照会で確認。
- `tests/bgm-links.sql` はロール切替によるDB契約検証用です。今回のツール実行は確認期限切れで完了せず、DB契約テストの成功は未確認です。実データに検証用リンクは登録していません。

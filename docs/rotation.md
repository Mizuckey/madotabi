# 動画の自動切替

## 利用する画面

トップページでログインし、「景色を見る」「URLを追加」を切り替えます。URLの保存に成功すると、その動画から連続視聴を始めます。タイトル・メモは任意の折りたたみ欄です。

旧 `/admin` は `/?view=add`、旧 `/admin/watch` は `/` にリダイレクトします。認証・RLS・既存の登録データは維持します。公開カタログは使用せず、公開状態を変更する操作もありません。単体視聴 `/watch/<YouTube動画ID>` は従来どおり利用できます。

## 操作

- 2件以上あると、初期設定の1分間隔で順番に自動切替します。
- 間隔は1秒〜60秒の範囲で1秒刻みで選択できます。
- 最後の動画の次は最初へ戻ります。
- 「自動切替を停止」で現在の動画を見続けられます。映像自体は止まりません。
- 「自動切替を再開」で、停止した時点の残り時間から再開します。
- 「前へ」「次へ」、選択欄、右側の一覧で手動切替できます。手動選択すると切替時間は設定した間隔にリセットされます。
- 間隔の変更時も、その間隔から数え直します。停止中に変更しても勝手に再開しません。
- 動画が0件・1件のときは、切替タイマーを作りません。

切替時間はYouTubeの再生中（PLAYING）の時間だけを数えます。最初の読み込み・バッファリング・YouTube内での一時停止・自動再生ブロック・終了・エラー中は残り時間を保持し、再生再開後に続けます。再生できない場合は再試行または手動で別の動画を選択してください。新しい動画の再生開始が20秒間確認できない場合は案内を表示します。景色を固定したい場合は「自動切替を停止」を使用してください。

ページを開き直した際は1分・自動切替ONに戻ります。localStorageへの設定保存やランダム再生は今回の範囲外です。

## 実装

- `useCameraRotation`: Reactの標準Hooksで、選択位置・間隔・停止/再開を管理。
- `startRotationTimer`: 単発の切替予約と残り時間表示。停止・画面離脱・手動切替時に予約を解除。
- 動画切替には同じプレーヤーの `loadVideoById` を使います。iframeとプレーヤーを作り直すのは初回・再試行・画面への再入場のみです。画面離脱時には破棄し、同時に複数を再生しません。音量・ミュートの選択は切替後も維持します。
- タイマーは単調増加時計を使い、残り時間を負にしません。
- ブラウザのバックグラウンド制限などで実行が遅れた場合も、複数本をまとめて飛ばさず次の1本へ進みます。タイマーの実行時刻はブラウザの制限で遅れる場合があります（[MDN setTimeout](https://developer.mozilla.org/en-US/docs/Web/API/Window/setTimeout#timeouts_in_inactive_tabs)）。
- 管理者用一覧は認証済みクライアントで100件ずつ取得し、メモは取得しません。公開カタログや保存データは変更しません。

## 検証

Node.js標準テストで、期限前に進まないこと、期限で1回だけ進むこと、停止と残り時間からの再開、古いタイマーの解除、末尾からの循環、画面離脱・Strict Mode相当の再マウント、遅延時の動作を確認しています。

ローカルの検証専用画面で実際のYouTube映像を使用し、30秒での動画変更と再生継続、自動切替の停止を確認しています。検証画面は`work/`内にあり、本番には含まれません。

## 読み込み改善

映像同士を重ねるフェードや隠れたプレーヤーでの先行再生は行いません。読み込み・エラーの案内は映像を覆わずプレーヤーの下に表示します。YouTube側のバッファリング自体は残るため、待ち時間ゼロは保証しません。

改善時のブラウザ検証では、実際の3動画を同じiframe（1個）で切替・再生できること、YouTube内の一時停止中に残り時間が保持されることを確認しました。検証専用の疑似APIでも、設定間隔を超える読み込み待ち・バッファリング中に進まないこと、再生通知後に切り替わること、旧動画の通知を無視すること、エラー表示、再試行時だけiframeを再生成することを確認しています。疑似APIや検証画面は `work/` に置き、本番には含めません。

## 画面の配置

通常の視聴画面は100dvhに収め、コンパクトなヘッダー、残りの動画領域、映像外の情報帯で構成します。横幅1100px以上では再生操作もヘッダーへまとめ、それより狭い画面では下部の1〜2行に配置します。右サイドパネルやページ末尾のフッターは視聴画面に表示しません。映像は切り抜かず、縦横比に応じてYouTube内に余白が入ります。

情報帯には登録タイトルと「位置：未登録」「天気：未取得」を表示します。位置や天気の連携は今回追加していません。48秒周期で流れ、「固定」で停止、ホバー・キーボードフォーカス中も停止します。OSの動きを減らす設定では自動では流れません。

URL追加画面の長いフォームや一覧は専用領域内でスクロールします。高さ460px以下の極端に低い画面では、YouTubeの最小サイズと操作性を確保するためページスクロールを許可します。

ローカルで1280×720、1366×768、390×844の表示を確認し、ページの縦横はみ出しがないこと、追加画面の内部スクロール、情報帯の停止・再開を確認しています。

# 動画の自動切替

## 利用する画面

トップページでログインし、「景色を見る」「URLを追加」を切り替えます。URLの保存に成功すると、その動画から連続視聴を始めます。タイトル・メモは任意の折りたたみ欄です。

旧 `/admin` は `/?view=add`、旧 `/admin/watch` は `/` にリダイレクトします。認証・RLS・既存の登録データは維持します。公開カタログは使用せず、公開状態を変更する操作もありません。単体視聴 `/watch/<YouTube動画ID>` は従来どおり利用できます。

## 操作

- 2件以上あると、初期設定の1分間隔で順番に自動切替します。
- 間隔は1秒〜60秒の範囲で1秒刻みで選択できます。
- 最後の動画の次は最初へ戻ります。
- 「自動切替を停止」で現在の動画を見続けられます。映像自体は止まりません。
- 「自動切替を再開」で、停止した時点の残り時間から再開します。
- 「前へ」「次へ」、選択欄、右側の一覧で手動切替できます。手動選択すると切替時間は設定した間隔にリセットされます。
- 間隔の変更時も、その間隔から数え直します。停止中に変更しても勝手に再開しません。
- 動画が0件・1件のときは、切替タイマーを作りません。

切替時間は動画の選択・表示時から数えます。YouTubeプレーヤー内での一時停止や読み込み待ちとは独立しています。景色を固定したい場合は「自動切替を停止」を使用してください。再生できない動画でも、自動切替中なら設定時間後に次へ進みます。

ページを開き直した際は1分・自動切替ONに戻ります。localStorageへの設定保存やランダム再生は今回の範囲外です。

## 実装

- `useCameraRotation`: Reactの標準Hooksで、選択位置・間隔・停止/再開を管理。
- `startRotationTimer`: 単発の切替予約と残り時間表示。停止・画面離脱・手動切替時に予約を解除。
- 動画切替に伴うプレーヤー破棄は既存のCameraPlayerが行い、同時に複数の音声を流しません。
- タイマーは単調増加時計を使い、残り時間を負にしません。
- ブラウザのバックグラウンド制限などで実行が遅れた場合も、複数本をまとめて飛ばさず次の1本へ進みます。タイマーの実行時刻はブラウザの制限で遅れる場合があります（[MDN setTimeout](https://developer.mozilla.org/en-US/docs/Web/API/Window/setTimeout#timeouts_in_inactive_tabs)）。
- 管理者用一覧は認証済みクライアントで100件ずつ取得し、メモは取得しません。公開カタログや保存データは変更しません。

## 検証

Node.js標準テストで、期限前に進まないこと、期限で1回だけ進むこと、停止と残り時間からの再開、古いタイマーの解除、末尾からの循環、画面離脱・Strict Mode相当の再マウント、遅延時の動作を確認しています。

ローカルの検証専用画面で実際のYouTube映像を使用し、30秒での動画変更と再生継続、自動切替の停止を確認しています。検証画面は`work/`内にあり、本番には含まれません。
